Synthetic dataset based on the FOAF ontology.

Four datasets were created, with 6, 10, 14 and 20 people entities respectively. Each dataset is represented with 8 different formats:
  -natural language, natural.txt
  -natural language encapsulated within a JSON structure, natural.json
  -represented as properties within XML using numeric identifiers, foaf.xml
  -represented as properties within JSON using numeric identifiers, foaf.json
  -represented as properties within an RDF framework using numeric identifiers, foaf.rdf
  -represented as properties within XML using full-name identifiers, foaf_names.xml
  -represented as properties within JSON using full-name identifiers, foaf_names.json
  -represented as properties within an RDF framework using full-name identifiers, foaf_names.rdf


The experiments utilizing the LLM and these formats are grouped based on the utilized method or the utilized LLM. Some experiments were attempted multiple times, for which there are multiple xlsx files, named as "testN.xlsx", where N represents the repetition of that experiment.
